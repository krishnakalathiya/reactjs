# Documentation Blog Project 📝

## 🔹 Project Description
The Documentation Blog Project is a web application developed using **ReactJS** that allows users to read, manage, and organize documentation articles or blog posts in a structured format. It is designed as a Single Page Application (SPA) using React Router to navigate between pages smoothly without reloading the website. 

The project demonstrates core frontend development concepts, utilizing local storage for data persistence (`LocalStorage`) so that your articles remain saved even after refreshing the browser. It features a clean, responsive layout that seamlessly adapts to different device screen sizes.

---

## 🔹 What is Included in This Project
* **Home Page:** Displays a website introduction, a structured navigation menu, and a section for featured blogs.
* **Blog Listing Page:** Shows all available documentation/blog posts with their titles, categories, and short descriptions.
* **Blog Details Page:** Renders the full blog content along with its title and category information.
* **Add Blog Feature:** Provides form inputs for users to enter a new blog title, choose a category, and supply content.
* **Search Functionality:** Allows users to search and filter blogs by title to quickly locate specific documentation topics.
* **Full CRUD Operations:** Supports creating new blogs, viewing blogs, updating/editing content, and removing/deleting blogs.
* **Responsive Layout:** A modular interface configured to support mobile devices, tablets, and desktop screens.

---

## 🔹 How This Project is Made
* **Component-Based Architecture:** The interface is broken down into reusable components like `Navbar`, `BlogCard`, `Footer`, and `Forms` to improve code maintainability and readability.
* **JSX Syntax:** Used to write HTML-like structures inside JavaScript to handle dynamic rendering and UI element management.
* **Props Configuration:** Implements explicit parent-to-child data flow patterns, such as passing specific article records directly into individual card components.
* **State Management:** Employs built-in React hooks like `useState()` to store local blog data arrays, manage active form input values, and update the UI layout on the fly.
* **Client-Side Routing:** Managed via React Router DOM to maintain application states across unique view URLs (`Home`, `Blogs`, `Blog Details`, `Add Blog`) seamlessly.
* **Conditional Rendering:** Uses evaluation conditions to cleanly present search query matches, output context messages, and handle empty blog list scenarios.

---

## 🔹 Technologies Used
* **ReactJS** – Frontend JavaScript library
* **Vite** – Fast, modern project build tool
* **React Router DOM** – Client-side page navigation
* **JavaScript (ES6)** – Application logic and operational functionality
* **CSS3** – Layout styling and responsive media designs
* **LocalStorage** – Browser data persistence for persistent CRUD mock states
